# ✉️ Анимированный конверт с письмом

Одностраничный проект с анимированным конвертом, из которого при нажатии на кнопку «достаётся» письмо с извинениями.

## 🎬 Демонстрация

- Закрытый конверт с восковой печатью «Я&Н»
- Кнопка «Открыть письмо» с элегантным hover-эффектом
- При клике: клапан конверта открывается (3D-поворот), письмо плавно выезжает вверх, конверт уходит на второй план
- Письмо разворачивается на весь экран с деловым текстом извинений
- Возможность свернуть письмо кнопкой, кликом по фону или клавишей Escape

## 🚀 Запуск

Просто откройте `index.html` в браузере. Никаких сборщиков и зависимостей не требуется.

## 🎨 Особенности

- **Чистый HTML/CSS/JS** — без внешних библиотек и картинок
- **3D-анимация** — `transform: rotateX` и `transform-style: preserve-3d` для клапана
- **Плавные переходы** — все анимации через `transition` и `@keyframes` с easing `cubic-bezier(0.4, 0, 0.2, 1)`
- **Адаптивность** — корректное отображение на мобильных устройствах
- **Премиальный стиль** — сдержанная палитра (кремовый, золотистый, пыльно-голубой акцент)

## 📱 Управление

| Действие | Результат |
|----------|-----------|
| Клик по кнопке «Открыть письмо» | Открытие конверта и показ письма |
| Клик по кнопке «Свернуть» | Возврат в исходное состояние |
| Клик по фону (вне письма) | Закрытие письма |
| Клавиша `Escape` | Закрытие письма |
